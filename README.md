# Swim.ai 🏊‍♂️✨

**Everything. Delivered. Smart.**

Swim.ai is a next-generation local delivery and logistics application designed to provide lightning-fast deliveries of food, groceries, medicine, and retail products using AI-driven route optimization and smart logistics.

## 🚀 Key Features

- **Multi-Category Delivery**: Food, Healthcare, Groceries, and Local Boutiques all in one place.
- **Smart Logistics**: AI-assisted delivery tracking and assignment for maximum efficiency.
- **Advanced UI/UX**: A sleek, dark-themed interface built with React Native and Expo.
- **Real-Time Tracking**: Monitor your orders from the store to your doorstep.
- **Digital Wallet**: Seamless payments with the built-in Swim.ai Wallet.

## 📱 Tech Stack

- **Core**: React Native v0.81 (SDK 54)
- **Framework**: Expo
- **State Management**: Zustand
- **Navigation**: React Navigation v7
- **Animations**: React Native Reanimated
- **Icons**: Expo Vector Icons (Ionicons)

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)
- [iOS Simulator](https://docs.expo.dev/workflow/ios-simulator/) (for Mac) or [Android Emulator](https://docs.expo.dev/workflow/android-studio-emulator/)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Adhilz/Swim.app.git
   cd Swim.app
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm start
   ```

4. **Launch the app**:
   - Press `i` for iOS
   - Press `a` for Android
   - Scan the QR code with the Expo Go app
